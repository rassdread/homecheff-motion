# Editor V6 Report

## Quick Action Bar

Large-button bar on selection: Replace, Remove, Cut out, Save, Animate, Duplicate. Human labels only.

## One Click Cutout

"Object losmaken" creates transparent PNG via SAM2/segment, saves to Library cutouts category, downloadable and reusable.

## Drag From Library

Library panel supports click and drag onto canvas. Cutouts, logos, mascots, and products become imported layers.

## Magic Replace

Upload or prompt-based replace with preview-then-apply flow. Example prompts built in.

## Background Tools

Remove, blur, replace, expand, transparent export, sky, gradient, and HomeCheff brand background.

## Alignment Tools

Snap center/left/right/top/bottom, distribute horizontally/vertically, visual alignment guides on canvas.

## Brand Kit

HomeCheff Brand Kit with logos, colors, fonts, gradients, backgrounds, mascots — quick insert.

## Poster Builder

Templates: A4, A3, A2, A1, Instagram, Flyer, Menu, Event, Restaurant, Marketplace with safe margins.

## Social Media Kit

Instagram Post/Story, TikTok, YouTube, Facebook, LinkedIn, X, Pinterest — auto resize export settings.

## Motion Ready Preview

Float, Rotate, Pulse, Bounce, Orbit, Reveal, Wave — realtime overlay preview, no render wait.

## Studio Handoff Score

Motion Ready percentage with checks (objects isolated, masks, cutouts, export safe) and warnings.

## Human First Cleanup

Technical metadata remains admin-only via existing UX cleanup + AI analysis toggle.
