# Studio Scene Image Planner (V27)

Planning layer bridging storyboards and scene image generation.

## Shipped in V27

- Per-scene image requirements (cast, location, objects, mood, time, framing)
- Storyboard-level character / location / prop registries (from scene links)
- Continuity warnings (disappearing cast/mascots, clothing shifts, location jumps)
- Visual consistency score and readiness tier
- AI scene description line per scene
- Export: image generation, Vidu context, storyboard visual prompts (copy in UI)

## Possible follow-ups

- LLM-enriched scene descriptions from brief + world memory
- Persist planner snapshots per storyboard revision
- One-click “apply requirements” to scene composer fields
- Integration with bulk `generate_scene_images` job preflight
