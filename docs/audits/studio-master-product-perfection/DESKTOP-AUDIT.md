# Desktop Audit

## Strengths

- Studio home intents readable at 1280–1440
- Story workspace can feel like a real production tool (preview + inspector + stages)
- Pricing/account pages are conventional SaaS layouts

## Gaps

| Issue | Pri | Class |
|---|---|---|
| Multiple simultaneous “product homes” in shell nav reduce professional focus | P1 | IA |
| Advanced tools (Production/Movie/Providers) still discoverable → intimidation for new users | P2 | UX |
| Dual music/director panels = visual noise for power users too | P2 | UX |
| Whitespace/hierarchy varies by legacy surface (Instant vs Studio vs Editor) | P2 | CONSISTENCY |

## Professional workspace test

Does it feel like one creation studio? **Not yet** — feels like Studio + Motion + Videos suite sharing a shell.
