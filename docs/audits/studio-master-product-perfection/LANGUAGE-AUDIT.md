# Language / Translation Audit

## Capability honesty

Replacing text **inside** already-rendered imagery/video ≠ overlay translation. Prior product principle: do not overpromise.

| Feature | Class |
|---|---|
| Overlay / subtitle-style language tooling where implemented | LIMITED / RELIABLE_CURRENT (context-dependent) |
| Language export panel on videos/workspace | LIMITED — multiple mounts |
| “Translate my finished cinematic video pixels” | EXPERIMENTAL / HIDE_UNTIL_READY |
| Version Center language tabs | ADVANCED |

## Trust risk

UI that implies full video re-language without clarifying overlay-vs-re-render will burn trust.

**Recommended product action:** DE-EMPHASIZE language export for normal users; keep for advanced/completed Instant outputs with honest copy.
