# Risks and open questions

## Critical

1. Production and preview share one database. Any migration later is a production change. V11 applied none.
2. A director that calls today’s generation routes can spend HC, because not every route requires a prior quote. The quote gate has to land before tool execution.
3. Regenerating Baker, Potter, or Gardener would replace masters the film depends on. The action schema must reject those ids.
4. Kling and Runway appear in provider capability flags and are not server adapters. Shipping a button for them would be a false capability.

## High

5. Storyboard, video, and editor pages are separate applications. Embedding the storyboard without forking it is the main engineering risk of phase 1.
6. Passion’s creative project has null storyboard and animation links. The shell must not invent a second project to compensate.
7. Two chosen videos were already missing in V10, and six renders were stale. The library hides them from finished work. The project page can still show rendering. The shell should use the same classifier.
8. Refund-on-failure is implemented as a function. Coverage for every Vidu timeout was not re-proven in this audit.
9. Competitor 4K, credit math, and “coming soon” lines conflict across official pages. Do not copy those numbers into HomeCheff pricing.

## Open questions

- Can Dutch subtitles for Passion be authored text only, or is transcription required? Authored text avoids an STT charge.
- Is the narrator a fourth character without a master image, or a project-level voice? A voice-only character reuses the character editor.
- Does one Vidu project hold a 55-second cut, or do segments stay separate until export? The schema supports multiple transitions. Confirm duration limits in the Vidu adapter before promising 55 seconds in one request.
- Which planner model, if any, the director chat will call, and its HC price. The current wizard does not call one.

## Explicitly not done

No production mutation, no migration, no deploy, no paid provider call, no HC charge, no browser end-to-end, no Marketplace or Growth edit, no media regeneration.
