# Brand implementation

The workspace uses the existing tokens, not a new palette.

| Role | Value | Where |
|---|---|---|
| Page and left nav | `#041428` | Shell |
| Selected nav and focus | `#0067B1` | Sidebar current item, focus ring, selected character |
| Primary actions and text links | `#006D52` and the existing gradient button token | Empty-state action, download |
| Content | Light card `studioVisual.cardLight` | Forms, lists, counts |
| Preview | Dark well | Image or existing video |
| Mark | `ECOSYSTEM_BRAND_MARK_URL` | Sidebar |

Marketplace and Growth were not edited.

Below the large desktop layout, the left nav and the details panel become explicit drawers. Section tabs scroll horizontally instead of shrinking into an unreadable row.

The one primary gradient button is the existing Studio token. It is used for a real navigation action, not for decoration across the page.
