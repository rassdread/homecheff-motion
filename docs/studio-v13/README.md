# Studio V13 — film preparation inside the project

The unified workspace at `/studio/projects/[id]` can now prepare a film: link a storyboard, manage scenes, assign existing characters, save Dutch subtitle text, save film-level narration, choose an existing still, and attach an existing video project.

It stays on the V11 model. `StudioCreativeProject` is the film. No new film, scene, character, subtitle, or animation table was added.
