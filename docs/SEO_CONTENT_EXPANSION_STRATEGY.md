# SEO Content Expansion Strategy

**Product:** HomeCheff Studio  
**Date:** June 2026  
**Scope:** 7 workflow pillars · NL-first intents · 5 integrated roadmaps

---

## Executive summary

HomeCheff Studio groeit van **technische SEO-basis** (metadata, sitemap, structured data) naar **topic authority** via zeven workflow-pijlers. Elke pagina vertelt hetzelfde productverhaal:

```
Idee → Wereld → Personages → Stemmen → Scènes → Video → Vertaling → Publicatie
```

| Module | HomeCheff surface | SEO-rol |
|--------|-------------------|---------|
| Idee | Studio production brief, storyboards | Top-funnel intent |
| Wereld | Studio worlds, locations | Consistency / series |
| Personages | Studio characters, Editor assets | Character-first queries |
| Stemmen | Voice library, clone | Voice / dubbing intent |
| Scènes | Storyboard scenes, scene images | Story-first differentiation |
| Video | Motion (image-to-video), assembly | AI video generator intent |
| Vertaling | Language export, subtitles | Localization intent |
| Publicatie | Publish, versions | Marketing / trailer intent |

**Gerelateerde docs:** `SEO_CREATOR_DREAMS_NL_CLUSTERS.md` · `SEO_COMPARISON_ALTERNATIVE_ROADMAP.md` · `SEO_CREATOR_DREAM_ROADMAP.md`

## Brand & trademark guardrails

HomeCheff is **niet** Disney, Pixar, DreamWorks, Paramount, Warner Bros of Netflix.

| Regel | Toepassing |
|-------|------------|
| **Vergelijking & inspiratie alleen** | “Pixar-achtige workflow” = planningsdiscipline, niet stijl-kopie |
| **Geen merknamen in URL’s** | Gebruik `/guides/eigen-animatie-studio-workflow`, niet `/pixar-workflow` |
| **Disclaimer op inspiratiepagina’s** | *HomeCheff Studio is niet gelieerd met [merk]. Trademarks zijn eigendom van hun houders.* |
| **Geen logo’s of karakters** | Geen Disney/Pixar/Netflix assets in OG-images of screenshots |
| **Geen misleidende claims** | Geen “Netflix-kwaliteit”, “Disney-goedkeuring”, of distributie-beloften |
| **DreamWorks-achtig** | Zelfde regels als Pixar/Disney — generieke “grote animatiestudio-workflow” in body |

**Goedgekeurde formulering:** *“Werk zoals grote studio’s: eerst verhaal en wereld, dan pas animatie — met AI-assistentie in HomeCheff Studio.”*

# 1. SEO ROADMAP

## 1.1 Keyword-architectuur

```
/                           → Suite + productielijn (breed)
/guides/{workflow}/{slug}   → Pijler-landings (commercial + aspirational)
/help/{slug}                → Long-tail + how-to (informational)
/workflows/{pillar}         → Pijler-hubs (topic authority)
/inspiration/{slug}         → Studio-workflow inspiratie (geen merk-URLs)
/alternatives/{tool}        → Tool-vergelijking (zie comparison roadmap)
/tutorials/{slug}           → HowTo + conversie
```

## 1.2 Pijler × SEO-thema’s

### Creator Dreams
- **Primair:** eigen cartoon, anime, animatieserie, filmstudio, dromen van filmmaker worden
- **Secundair:** AI animation studio, digital production studio
- **Content-type:** aspirational guides, serie-workflows
- **Golf 1:** cartoon, animatieserie, filmstudio

### Artist Workflows
- **Primair:** tekening animeren, schets naar video, illustratie tot leven
- **Secundair:** manga-stijl, reference upload, image fusion
- **Content-type:** Editor-first tutorials
- **Golf 1:** tekeningen tot leven, schets naar animatie

### Filmmaker Workflows
- **Primair:** verhaal naar film, eigen regisseur, filmstudio opzetten
- **Secundair:** storyboard discipline, director mode, scene planning
- **Inspiratie (geen merk-URLs):** animatie-studio-workflow, verhaalstudio-workflow
- **Golf 1:** verhaal naar video, word regisseur · **Golf 3:** Pixar/Disney/DreamWorks-achtig (disclaimer)

### Writer Workflows
- **Primair:** boek naar film, verhaal naar video, boek trailer
- **Secundair:** acts/scenes structuur, production brief vanuit manuscript
- **Golf 2:** boek naar film/trailer

### Marketing Workflows
- **Primair:** contentteam met AI, campagnevideo, social video serie
- **Secundair:** meertalige versies, brand consistency
- **Golf 2:** contentteam, trailer-workflows

### Education Workflows
- **Primair:** video voor les, student project, uitlegvideo maken
- **Secundair:** ondertiteling voor toegankelijkheid, vertaling voor klas
- **Golf 3:** education hub + 6 help-artikelen

### Gaming Workflows
- **Primair:** game trailer, cutscene, character lore video
- **Secundair:** consistent game art, world bible → video
- **Golf 3:** gaming hub + character/world cross-links

# 5. STRUCTURED DATA ROADMAP

## 5.1 Huidige basis (live)

| Schema | Locatie | Status |
|--------|---------|--------|
| Organization | Root layout | ✅ |
| WebSite + SearchAction | Root layout | ✅ |
| SoftwareApplication | Root layout | ✅ |
| FAQPage | `/pricing` | ✅ |
| Article | `/help/[slug]` | ✅ |
| BreadcrumbList | Help articles | ✅ |

## 5.2 Uitbreiding per contenttype

### Pijler-hubs (`/workflows/*`)

```json
{
  "@type": "CollectionPage",
  "name": "Filmmaker Workflows",
  "description": "...",
  "hasPart": [ { "@type": "WebPage", "url": "/guides/..." } ]
}
```

+ `BreadcrumbList`: Home → Workflows → Pijler

### Guide landings (`/guides/*`)

| Schema | Wanneer |
|--------|---------|
| `WebPage` + `BreadcrumbList` | Altijd |
| `FAQPage` | ≥5 FAQ’s op pagina |
| `HowTo` | Als stappen statisch (overlap met tutorials) |
| `SoftwareApplication` | **Niet** dupliceren — verwijs via `mentions` naar suite |

**Voorbeeld HowTo (schets → animatie):**

```json
{
  "@type": "HowTo",
  "name": "Van schets naar animatie",
  "step": [
    { "@type": "HowToStep", "name": "Upload schets", "url": "...#stap-1" },
    { "@type": "HowToStep", "name": "Scene in Studio", "url": "...#stap-2" },
    { "@type": "HowToStep", "name": "Animeer in Motion", "url": "...#stap-3" }
  ],
  "tool": { "@type": "HowToTool", "name": "HomeCheff Studio" }
}
```

### Help artikelen

- Behoud `Article` + `BreadcrumbList`
- Voeg `about` → `Thing` met pijler-naam
- Optioneel `LearningResource` voor Education-pijler

### Tutorials (`/tutorials/*`)

- Primair `HowTo` + `VideoObject` wanneer video beschikbaar
- `duration` + `supply` per stap

### Inspiratiepagina’s (Pixar/Disney/DreamWorks-achtig)

- **Alleen** `Article` + disclaimer in `description`
- **Geen** `Brand` schema voor externe studio’s
- `mentions`: generiek “animation studio workflow” als `Thing`, geen trademark entities

### Vergelijkingspagina’s (`/alternatives/*`)

- `FAQPage` + `BreadcrumbList`
- Optioneel `Product` voor HomeCheff Studio met `isSimilarTo` → **vermijd** externe Product entities (trademark risico)
