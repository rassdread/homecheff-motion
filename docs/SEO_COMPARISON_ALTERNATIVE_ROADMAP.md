# Comparison & Alternative SEO Roadmap

**Product:** HomeCheff Studio  
**Date:** June 2026  
**Status:** Planning — no thin pages at launch

This roadmap covers **comparison landers** (`/canva-alternative`) and **“without X” content clusters** (`zonder Photoshop`, etc.). All pages require substantive original content before publish — see [quality gate](#quality-gate-before-publish).

---

## HomeCheff differentiators (use on every comparison page)

| Strength | Message | Proof surface |
|----------|---------|---------------|
| **All-in-one** | Editor → Studio → Motion → Publish in one suite | `/`, production line sections |
| **Story-first workflow** | Plan scenes and storyboards before generating clips | `/studio` |
| **Reusable asset library** | Characters, worlds, props persist across projects | `/library` |
| **AI voice** | Voice library, character voices, clone path | Studio voice + help cluster |
| **Subtitles** | Auto-generate and style on-screen text | Help + Studio/Motion export |
| **Translation** | Multi-language versions from one master | Language export help |
| **Publishing** | Version lineage, formats, campaign outputs | `/publish` |
| **Project management** | One project across modules | `/projects` |

**Positioning line:** *HomeCheff Studio is an AI production line — not a single-purpose editor or generator.*

---

## Quality gate before publish

Each comparison or “without X” page must include:

- [ ] 1,000+ words original copy (EN; NL variant optional later)
- [ ] Honest feature comparison table (dated, factual)
- [ ] “Who should use what” section (include when competitor is still better)
- [ ] 3+ screenshots of HomeCheff workflow
- [ ] FAQ block (5+ questions) → FAQPage schema
- [ ] CTA: signup + `/pricing`
- [ ] Internal links (minimum 5): product hubs + 2 help articles
- [ ] Disclaimer: *HomeCheff Studio is not affiliated with [Competitor]. Trademarks belong to their owners.*
- [ ] No false parity claims (e.g. do not claim Photoshop-level compositing)

## Comparison pages — master roadmap

### 1. Photoshop alternative

| Field | Detail |
|-------|--------|
| **Search intent** | Commercial investigation — users want cloud/AI image editing without Adobe subscription or desktop install |
| **Primary queries** | `photoshop alternative`, `photoshop alternative free`, `online photoshop alternative`, `AI photoshop alternative` |
| **Secondary (NL)** | `photoshop alternatief`, `zonder photoshop foto bewerken` |
| **Recommended URL** | `/alternatives/photoshop` (hub) + anchor section on `/editor` |
| **Interim surface** | `/editor` — metadata already mentions “no Photoshop required” |
| **Priority** | P1 — Wave 2 (Month 2–3) |

**HomeCheff advantages vs Photoshop**

- Browser-based; no Creative Cloud lock-in
- AI-native: fusion, reference roles, character assets — not manual layer stacks
- Direct handoff to Studio storyboards and Motion video
- Credits-based pricing vs Adobe subscription

**Honest limitations**

- Not a pixel-perfect retouching or print-prepress tool
- No PSD ecosystem, plugins, or professional color grading suite

**Internal links**

| From | To |
|------|-----|
| Comparison page | `/editor`, `/editor/fuse`, `/studio`, `/pricing` |
| `/editor` landing | `/alternatives/photoshop`, `/help/editor-getting-started` (planned) |
| Help | `editor-image-fusion-workflow`, `send-asset-to-studio` (planned) |

### Per-cluster content outline

#### zonder Photoshop / without Photoshop

- **Intent:** “I can’t afford or learn Photoshop — what else creates brand assets?”
- **Angle:** AI image creation, fusion, reference roles in Editor
- **HomeCheff strengths:** Editor → Library → Studio handoff
- **Internal links:** `/editor`, `/alternatives/photoshop`, `editor-fusion-workflow`, `/library`
- **CTA:** Start in Editor free tier

#### zonder Canva / without Canva

- **Intent:** “Canva video is too template-y / I need consistent characters”
- **Angle:** Storyboard-first campaigns with reusable assets
- **HomeCheff strengths:** Studio storyboards, Motion, Publish versions
- **Internal links:** `/alternatives/canva`, `/studio`, `/publish`, `/pricing`
- **CTA:** Create first storyboard

#### zonder CapCut / without CapCut

- **Intent:** “I don’t want phone-only editing — I want AI clips”
- **Angle:** Web-based Motion wizard + project history
- **HomeCheff strengths:** Image-to-video, project dashboard
- **Internal links:** `/alternatives/capcut`, `/animate/instant`, `/projects`
- **CTA:** Generate first clip

#### zonder Premiere / without Premiere

- **Intent:** “Professional NLE is overkill for my social/campaign videos”
- **Angle:** AI assembly, subtitles, translation without timeline
- **HomeCheff strengths:** Publish, version lineage, automatic assembly
- **Internal links:** `/alternatives/premiere-pro`, `/publish`, `/help/publish-overview`
- **CTA:** See publishing workflow

#### zonder videobewerkingssoftware / without video editing software

- **Intent:** Broad NL query — beginners avoiding any traditional editor
- **Angle:** End-to-end AI production line explainer
- **HomeCheff strengths:** All-in-one, story-first, no timeline required
- **Internal links:** `/`, `/help/getting-started-with-studio`, all product hubs
- **CTA:** Production line tour (homepage sections)

#### zonder montage-ervaring / without editing experience

- **Intent:** Skill anxiety — “I’ve never edited before”
- **Angle:** Guided wizards, AI director, storyboard steps
- **HomeCheff strengths:** Studio guided flows, Motion wizard, onboarding checklist
- **Internal links:** `/help/getting-started-with-studio`, `/studio/start`, `/animate/instant`
- **CTA:** Onboarding checklist

## URL architecture

```
/alternatives                    → Comparison hub (index all competitors)
/alternatives/[competitor-slug]  → Individual comparison landers
/help/create-without-*           → “Zonder X” educational hubs (indexable)
/guides/*                        → Creator guides (see Creator Dream roadmap)
```

**Do not** use competitor names in URLs alone (`/canva-alternative` vs `/alternatives/canva`) — prefer `/alternatives/` namespace for maintainability.
