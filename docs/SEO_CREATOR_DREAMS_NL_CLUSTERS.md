# Creator Dreams SEO — NL Contentclusters

**Product:** HomeCheff Studio  
**Date:** June 2026  
**Taal:** Nederlands (primair) + Engelse equivalenten  
**Status:** Roadmap — geen dunne pagina’s publiceren vóór quality gate

Per cluster: **landing page**, **help-artikelen**, **vergelijkingspagina’s**, **tutorials**, **interne links**, **zoekintentie**, **conversiepad naar Studio**.

---

## URL-architectuur

```
/guides                          → Hub “Creator Dreams”
/guides/{slug}                   → Landing pages (NL primair)
/help/{slug}                     → Help Center (ondersteunend + long-tail)
/tutorials/{slug}                → Stap-voor-stap (video + screenshots later)
/alternatives/{competitor}       → Vergelijkingen (zie SEO_COMPARISON_ALTERNATIVE_ROADMAP)
/inspiration/{slug}              → Workflow-inspiratie (geen merk-URLs)
```

**Quality gate (elke landing):** ≥1.200 woorden · workflow-diagram · 5 FAQ’s · disclaimer bij studio-referenties · CTA naar Studio · min. 6 interne links.

---

## HomeCheff-conversiepad (standaard)

Elk cluster eindigt in dezelfde **Studio-funnel**, aangepast per intent:

```
Landing / Tutorial
    → Help-artikel (dieper)
    → /studio/start of /studio/storyboards/new   ← primaire conversie
    → /editor (als tekening/schets)
    → /animate/instant (als animatieclip)
    → /library (herbruikbare assets)
    → /projects (serie/episodes)
    → /publish (trailer/finale)
    → /signup + /pricing
```

**Primaire Studio-CTA copy (NL):** *“Begin met je storyboard in Studio”* → `/studio/storyboards/new`  
**Secundair:** *“Upload je schets in Editor”* → `/editor/start`
