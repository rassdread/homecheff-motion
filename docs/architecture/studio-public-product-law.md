# Studio public product law (SP.3)

## Law

HomeCheff Studio must first feel like an **open website**.

| Class | Rule |
|-------|------|
| PUBLIC INFORMATION | Open without login (what / who / how / examples / pricing / help) |
| PUBLIC PRODUCT DISCOVERY | Product landings (`/editor`, `/studio`, `/motion`, `/publish`, `/library`, `/studio/experience`) explain before create |
| AUTHENTICATED CREATION | `/…/start`, workspaces, generate, publish execution |
| ACCOUNT/BILLING | Auth required |

## Navigation

Anonymous suite tabs must open **discovery** pages, not login walls.

Creation CTAs on those pages may require authentication and must preserve `next` / intended journey.

## First impression

Primary CTA = start from an idea (guided experience).  
Secondary = understand the product.  
Tertiary = advanced tools (Editor, Motion, …).

Editor is a powerful tool — not the conceptual center of Studio for new visitors.
